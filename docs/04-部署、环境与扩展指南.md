# 04. 部署、环境与扩展指南

## 4.1 本地开发环境

推荐使用：

- PHP 8.2
- Composer
- Node.js 18+ / 20+
- MySQL 8.0
- NPM

> Windows 环境下可使用本地 MySQL 服务或 Docker；本项目同样适合在 WSL / Linux / MacOS 环境中开发。

## 4.2 安装步骤

### 1 安装 PHP 依赖

```bash
composer install
```

### 2 安装前端依赖

```bash
npm install
```

### 3 准备环境变量

复制环境文件：

```bash
cp .env.example .env
```

然后配置：

- DB_DATABASE
- DB_USERNAME
- DB_PASSWORD
- APP_KEY
- APP_URL

### 4 生成应用 key

```bash
php artisan key:generate
```

### 5 执行数据库迁移

```bash
php artisan migrate
```

### 6 初始化基础种子

```bash
php artisan db:seed
```

如果需要按模块单独初始化：

```bash
php artisan db:seed DictSeeder
php artisan db:seed ManagerSeeder
php artisan db:seed MenuSeeder
```

## 4.3 前端开发命令

### 启动 Vite

```bash
npm run dev
```

### 构建生产资源

```bash
npm run build
```

## 4.4 项目运行验证

已实际执行并验证：

```bash
npm run build
```

验证结论：

- 产物成功生成到 public/build
- Vue 模板编译正常
- 项目当前前端配置可继续扩展和部署

## 4.5 本地 Windows / 开发环境实战

### 1 Windows 下常用启动顺序

推荐以如下顺序启动：

```powershell
# 1) 进入项目目录
cd E:\simplecms\simplecms

# 2) 安装 PHP 依赖
composer install

# 3) 安装前端依赖
npm install

# 4) 复制环境变量文件并配置数据库
copy .env.example .env

# 5) 生成应用 key
php artisan key:generate

# 6) 执行数据库迁移
php artisan migrate

# 7) 初始化基础数据（如需）
php artisan db:seed

# 8) 启动前端开发服务器
npm run dev
```

如果本地 MySQL 处于服务状态，可将 `.env` 中配置为：

```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=simplecms
DB_USERNAME=root
DB_PASSWORD=your_password
```

如需绕过 MySQL，可在本地开发环境中使用 SQLite；但生产和正式测试环境建议保持 MySQL 8.0 或更高版本。

### 2 常见启动问题

#### 问题：`php artisan` 提示未配置数据库

检查：

```bash
php artisan config:clear
php artisan cache:clear
```

然后确认 `.env` 中数据库配置已写入，并重新执行：

```bash
php artisan migrate
```

#### 问题：前端页面空白或 JS 报错

检查：

```bash
npm run build
```

如果生产构建失败，通常属于：

- Vue 组件引用错误
- 资源路径问题
- `Inertia` 与页面 props 不匹配
- 环境变量缺失

#### 问题：`npm run dev` 无法启动

确认：

```bash
node -v
npm -v
```

如果 Node 版本过低，建议升级到 Node 18 / 20 LTS。升级后重新执行：

```bash
npm install
npm run dev
```

## 4.6 生产部署建议

### 1 生产环境准备

生产环境建议满足：

- PHP 8.2+
- Composer
- Nginx / Apache
- MySQL 8.0+
- Node.js 18+（仅用于构建前端资源）
- Redis（可选，用于缓存/队列）

### 2 部署步骤

```bash
composer install --no-dev --optimize-autoloader
npm install
npm run build
php artisan migrate --force
php artisan config:cache
php artisan route:cache
php artisan view:cache
php artisan storage:link
```

### 3 Web 服务器配置建议

Nginx 示例：

```nginx
server {
    listen 80;
    server_name example.com;
    root /var/www/simplecms/public;
    index index.php;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        include fastcgi_params;
        fastcgi_pass unix:/run/php/php8.2-fpm.sock;
        fastcgi_index index.php;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
    }
}
```

### 4 生产环境注意事项

- 生产环境必须配置强密码和安全访问策略
- `APP_ENV=production`
- `APP_DEBUG=false`
- 建议使用 HTTPS
- 资源文件和上传文件使用独立目录挂载
- 对关键页面和 API 接口启用速率限制或缓存策略

### 4.5 Local Windows and Development Workflow

#### 1 Typical startup steps on Windows

Recommended order:

```powershell
# 1) Go to the project folder
cd E:\simplecms\simplecms

# 2) Install PHP dependencies
composer install

# 3) Install frontend dependencies
npm install

# 4) Copy the environment file and configure the database
copy .env.example .env

# 5) Generate the app key
php artisan key:generate

# 6) Run database migrations
php artisan migrate

# 7) Initialize the base seed data if needed

```

A typical local MySQL configuration in `.env` is:

```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=simplecms

DB_PASSWORD=your_password
```

You may also use SQLite in a lightweight local environment, but MySQL 8.0+ remains the recommended production-ready option.

#### 2 Common startup issues

##### Problem: `php artisan` reports missing database configuration

Run:

```bash
php artisan config:clear
php artisan cache:clear
```

Then confirm that the database values in `.env` are correct and run:

```bash
php artisan migrate
```

##### Problem: frontend appears blank or JavaScript errors occur

Check the build:

```bash
npm run build
```

This usually points to:

- component import errors
- broken asset paths
- mismatched `Inertia` page props
- missing environment values

##### Problem: `npm run dev` fails to start

Verify:

```bash
node -v
npm -v
```

If the Node version is too old, upgrade to Node 18 or 20 LTS and reinstall dependencies:

```bash
npm install
npm run dev
```
