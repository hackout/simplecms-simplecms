# 01. 项目概览

## 1.1 项目定位

SimpleCMS 是一个以 SimpleCMS-Framework 为核心能力层、Laravel 12 为后端基础、Inertia + Vue 3 为前端渲染方案的 CMS 产品化工程。它不仅是一个演示型项目，更是一个以 SimpleCMS 为 IP 和品牌承载的统一能力平台：

- SimpleCMS-Framework：提供统一的模块化能力、服务抽象、权限机制和后台基础结构
- Laravel 12：负责应用骨架、路由、认证、数据库和业务流程编排
- Inertia + Vue 3：负责页面渲染、交互设计和企业展示层体验
- SimpleCMS IP：将内容管理、企业官网展示和后台运营能力统一封装为可复用产品能力

它同时覆盖两部分能力：

- 后台管理系统：用户、角色、权限、菜单、字典、日志等管理能力
- 前端展示系统：企业官网首页、关于页、服务页、方案页、产品页、案例页、新闻页、联系页等展示型页面

这使其不只是传统 CMS，而是兼具“内容管理”和“企业展示”的平台型基础结构。

## English / 英文

### 1.1 Project Positioning

SimpleCMS is a productized CMS project built around the SimpleCMS-Framework, with Laravel 12 as the backend foundation and Inertia + Vue 3 as the frontend rendering stack. It is not merely a demo; it is a reusable SimpleCMS IP and product platform that integrates content management, enterprise presentation, and background operations.

- SimpleCMS-Framework: provides modular capability, service abstraction, permission mechanisms, and backend foundation structure
- Laravel 12: handles the application skeleton, routing, authentication, database, and business orchestration
- Inertia + Vue 3: provides page rendering, interaction design, and enterprise-grade user experience
- SimpleCMS IP: unifies content management, enterprise website presentation, and operational administration into a reusable product capability

It covers two complementary layers:

- Backend management system: user, role, permission, menu, dictionary, log, and account capabilities
- Frontend display system: home, about, service, solution, product, case, news, and contact pages

This gives the project a platform-level foundation rather than a simple CMS template.

### 1.2 Technology Stack

#### Backend

- PHP 8.2
- Laravel 12
- Sanctum
- Spatie Media Library
- Composer dependency management

#### Frontend

- Vue 3
- Inertia.js
- Vite
- Element Plus
- SCSS

#### Runtime Model

- Laravel serves backend routes, controllers, and data supply
- Inertia handles frontend component rendering and page data binding
- Vite compiles and builds frontend resources
- Page data is returned through controller-based routing, which fits moderate-scale content and enterprise-site scenarios
